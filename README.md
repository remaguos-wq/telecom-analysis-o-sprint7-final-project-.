# telecom-analysis-o-sprint7-final-project-.
Audité y limpié una base de 4,000 usuarios de telefonía, corrigiendo errores de captura y nulos estructurales. Mediante análisis estadístico y segmentación por edad y consumo, identifiqué oportunidades de venta del plan Premium en usuarios intensivos y diseñé estrategias de retención para adultos mayores y captación del segmento joven.
